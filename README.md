# YM Robber

Скачивание треков из Яндекс Музыки с полными метаданными (название, исполнитель, альбом, год, номер трека, обложка).

*для корректного отображения обложки не рекомендуется использовать стандартный Медиаплеер Windows*

## ⚠️ Disclaimer

**Данный инструмент создан исключительно в образовательных и личных целях.**

Программа использует неофициальный API и не связана с компанией ООО «Яндекс» и не одобрена ею. Пользователь несёт полную ответственность за соблюдение условий использования сервиса Яндекс Музыка.

**Пожалуйста, уважайте авторские права исполнителей и используйте загруженный контент только для личного прослушивания.**

## Возможности
- Скачивание треков, альбомов и плейлистов по ссылке
- Автоматическое получение OAuth-токена (при первом запуске)
- Сохранение метаданных в MP3-файл
- Встраивание обложки
- Скачивание файла обложки альбома отдельным файлом в папку с альбомом 
- Выбор папки для сохранения

## Требования
- Python 3.9 или выше
- Windows / macOS / Linux
- Для нормальной рбоаты нужно быть авторизованным на ЯМ

## Установка
### 1️⃣ Установка Python (если нет)
1) Перейдите на [python.org](https://www.python.org/)
2) Скачайте установщик для вашей ОС
   
    *Важно: при установке отметьте галочку "Add Python to PATH"*

4) Завершите установку

Проверка:
```bash
python --version

# если версия ниже 3.8, обновите
```

<br>

### 2️⃣ Установка uv
```bash
# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Проверка:
```bash
uv --version

# пример вывода "uv 0.12.10 ... "
```

<br>

### 2️⃣ Удаление старой версии программы
Для более гладкой установки новой версии; если у вас была установлена старая версия, удалите ее
```bash
uv tool uninstall ym-robber
```

<br>

### 3️⃣ Скачать проект
```bash
git clone --depth 1 https://github.com/HTnoj/music_downloader.git
```
```bash
cd music_downloader
```
```bash
# синхронизируем зависимости (создаст виртуальное окружение (.venv) и установит нужные библиотеки)
uv sync
```

Устанавливаем как глобальную команду
```bash
uv tool install .
```

<br>

После этого программу можно запустить из любого места в cmd\terminal, прописав:
```bash
# для работы асинхронной версии (быстрая скачка треков) *рекомендуемо
ym-robber-async

# для работы синхронной версии (более медленная скачка треков)
ym-robber
```

## Полезные флаги (для асинхронной версии)

### Тихий режим (`-q`, `--quiet`)
По умолчанию программа выводит в консоль логи. 
Если вы хотите видеть только прогресс-бары, используйте флаг `-q` или  `--quiet`:

```bash
uv run ym-robber-async -q
```
