# YM Robber

Скачивание треков из Яндекс Музыки с полными метаданными (название, исполнитель, альбом, год, номер трека, обложка).

*для корректного отображения обложки не рекомендуется использовать стандартный Медиаплеер Windows*

## Возможности

- Скачивание трека по ссылке
- Автоматическое получение OAuth-токена (при первом запуске)
- Сохранение метаданных в MP3-файл
- Встраивание обложки
- Выбор папки для сохранения

## Установка

```bash    
# Клонируйте репозиторий
git clone https://github.com/HTnoj/music_downloader.git
cd music_downloader

# Установите зависимости
pip install yandex-music mutagen requests pyperclip art
```



## Использование
```bash
python YM.py
```
